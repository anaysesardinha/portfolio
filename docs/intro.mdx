# Documentation Samples

:::info[Audience]
This page is for anyone browsing this portfolio, before they pick a
sample to read.
:::

This section holds full documentation samples, not isolated writing
snippets. Each sample shows a complete system, not just a handful of
pages:

- Information architecture
- A consistent template
- Defined ownership
- A review cadence

## Available samples

### Meridian Contract Logistics

An internal operations documentation set for a fictional third-party
logistics company. It covers one topic end to end: inbound receiving and
put-away, for warehouse staff and new hires.

Start with [About this sample](/docs/meridian-logistics/about-this-sample)
for the context, or jump straight into the docs from the sidebar.

## How this site is put together

The portfolio home links here. This page links to the Contributor Guide
and to the Meridian Contract Logistics sample, and the sample itself
splits into its four Diataxis sections plus a process page. Each card
below names its page type, carries its own description, and opens that
page in a new tab. Point at a card, or tab to it, and the diagram traces
the route back to the portfolio home:
