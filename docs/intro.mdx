# Documentation Samples

This section holds full documentation samples, not isolated writing snippets.
Each sample shows a complete system: information architecture, a consistent
template, defined ownership, and a review cadence, not just a handful of
pages.

## Available samples

### Meridian Contract Logistics

An internal operations documentation set for a fictional third-party
logistics company. It covers warehousing, inventory management, and
returns processing for warehouse staff, account managers, and new hires.

Start with [About this sample](/docs/meridian-logistics/about-this-sample)
for the context, or jump straight into the docs from the sidebar.

## How this site is put together

Read the [Contributor Guide](/docs/contributor-guide) for the writing
standards behind every sample on this site: how pages are structured, how
ownership and review cadence are tracked, and how cross-linking keeps every
page reachable.
