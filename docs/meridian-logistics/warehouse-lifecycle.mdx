# The warehouse lifecycle

Every unit in a Meridian warehouse moves through four stages:
receiving, storage, picking and pack-out, and outbound distribution.
Each stage hands inventory to the next only after a check confirms
it's ready. Every procedure in this documentation set protects one of
those handoffs. The stages flow in one direction:

<TreeDiagram layout="flow" data={lifecycleStages} label="Warehouse lifecycle stages" />

The following table repeats this flow for quick reference and names the
system staff use at each stage, Wayfinder WMS, Meridian's warehouse
management system. Later sections go into more depth on each stage:

| Stage | Key action | System/tool |
|---|---|---|
| Inbound receiving | Check the shipment against its paperwork and log it. | Wayfinder WMS |
| Storage | Move inventory into ambient, climate-monitored, cold chain, or bonded storage. | Wayfinder WMS |
| Order picking and pack-out | Generate a pick list, then pick, pack, and stage the order. | Wayfinder WMS |
| Outbound distribution | Verify the order one final time, then hand off to the carrier. | Wayfinder WMS, outbound carrier |

## Inbound receiving

A shipment arrives with an advance shipping notice (ASN), the document
a supplier sends before the goods arrive. Staff check the delivery
against the ASN and log it into Wayfinder WMS, Meridian's warehouse
management system, before it moves further.

That check covers three things:

- **Quantity**: the carton count matches the ASN.
- **Condition**: cartons carry no visible damage.
- **Paperwork**: the carrier's bill of lading, the document that lists
  the cargo and the shipping terms, matches the ASN on file.

A mismatch in any of these becomes a receiving discrepancy. Staff
resolve it through the [process for inbound receipt
discrepancies](/docs/meridian-logistics/process-inbound-receipt-discrepancy),
not with a workaround on the dock.

## Storage

Once staff finish receiving, inventory moves into one of four storage types:

- **Ambient**: storage with no temperature requirement.
- **Climate-monitored**: storage that keeps a controlled temperature
  range, short of full cold-chain handling.
- **Cold chain**: storage for perishable goods, such as food or
  pharmaceuticals, that stays refrigerated or frozen end to end.
- **Bonded**: storage for goods under customs control, pending duty
  payment.

A stock keeping unit (SKU), the identifier for a distinct product,
uses the storage type its client contract and its own properties
require. It does not depend on which space happens to be free that day.

## Order picking and pack-out

When an order comes in, Wayfinder WMS builds a pick list and sets each
item's priority automatically, using one of three methods:

- **FIFO** (first in, first out): ships whichever unit arrived first,
  regardless of expiration date.
- **FEFO** (first expired, first out): ships the unit closest to its
  expiration date first.
- **FMFO** (first manufactured, first out): ships the unit with the
  earliest manufacture date first.

Perishable SKUs in cold chain storage typically ship FEFO or FMFO.
SKUs with no expiration concern typically ship FIFO.

Once the list is ready, staff pick the items, pack them into shipping
containers, and stage the completed order for outbound handling.

## Outbound distribution

Where inbound receiving checks a shipment against someone else's
paperwork, this check verifies Meridian's own work. Staff compare the
packed order against the original order record in Wayfinder WMS before
handoff to the outbound carrier:

- **Item accuracy**: the packed SKUs match the order.
- **Quantity**: the packed count matches the order.
- **Labeling**: the shipping label and any required paperwork match
  the destination.

This check catches a pick-and-pack error before it reaches the
customer. That's why it exists as its own step, not an assumed part
of packing.

Once the carrier takes the shipment, Wayfinder WMS marks the order
**Shipped**. The client can then track it in ClearLane Visibility,
Meridian's client-facing real-time inventory visibility platform.
