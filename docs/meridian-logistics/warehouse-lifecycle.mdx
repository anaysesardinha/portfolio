# The Warehouse Lifecycle

:::info[Audience]
This page is for Warehouse Operations staff and new hires learning how
inventory moves through a Meridian site.
:::

Every unit passes through four stages in a Meridian warehouse. Each
stage moves inventory safely to the next one. This flow explains why
any single procedure exists. The four stages flow in one direction:

```mermaid
flowchart LR
    A[Inbound receiving] --> B[Storage]
    B --> C[Order picking & pack-out]
    C --> D[Outbound distribution]
```

## Inbound receiving

A shipment arrives. Staff check it against its paperwork and log it into
Wayfinder WMS, Meridian's warehouse management system. Staff verify
quantity and condition before the shipment moves further.

A mismatch becomes a receiving discrepancy. Staff resolve these by
following the [process for inbound receipt
discrepancies](/docs/meridian-logistics/process-inbound-receipt-discrepancy),
instead of creating workarounds on the dock.

## Storage

Once received, inventory moves into one of three storage types:

- _Ambient_ storage, for goods with no temperature requirement.
- _Climate-monitored_ storage, for goods that need a controlled
  temperature range but not full cold-chain handling.
- _Bonded_ storage, for goods held under customs control before duty is
  paid.

A _SKU_ (stock keeping unit, the identifier for a distinct product) uses
the storage type required by the client contract and the product
itself. It does not depend on which space happens to be free that day.

## Order picking and pack-out

When an order comes in, Wayfinder WMS generates a pick list. The list
uses the picking strategy that SKU requires: FIFO, FEFO, or FMFO, all
defined in the [glossary](/docs/meridian-logistics/reference/glossary).
Staff pick the items, pack them, and stage them for outbound.

## Outbound distribution

Staff verify packed orders against the original order one more time.
Then they hand the order off to the outbound carrier. This final check
catches a pick-and-pack error before it reaches the customer. That is why
it exists as its own step, not an assumed part of packing.
