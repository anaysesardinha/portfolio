# The warehouse lifecycle

:::info[Audience]
This page is for Warehouse Operations staff and new hires learning how
inventory moves through a Meridian site.
:::

Every unit passes through four stages in a Meridian warehouse. Each
stage moves inventory safely to the next one. This flow explains why
any single procedure exists. The four stages flow in one direction:

<TreeDiagram layout="flow" data={lifecycleStages} label="Warehouse lifecycle stages" />

Here is the same flow as a quick-reference table. The sections below it
go into more depth on each stage:

| Stage | Key action | System/tool |
|---|---|---|
| Inbound receiving | Check the shipment against its paperwork and log it. | Wayfinder WMS |
| Storage | Move inventory into ambient, climate-monitored, or bonded storage. | Wayfinder WMS |
| Order picking & pack-out | Generate a pick list, then pick, pack, and stage the order. | Wayfinder WMS |
| Outbound distribution | Verify the order one final time before handoff. | Outbound carrier |

## Inbound receiving

A shipment arrives. You check it against its paperwork and log it into
Wayfinder WMS, Meridian's warehouse management system. You verify
quantity and condition before the shipment moves further.

A mismatch becomes a receiving discrepancy. You resolve these by
following the [process for inbound receipt
discrepancies](/docs/meridian-logistics/process-inbound-receipt-discrepancy),
instead of creating workarounds on the dock.

## Storage

After you receive a shipment, inventory moves into one of three storage types:

- **Ambient** storage, for goods with no temperature requirement.
- **Climate-monitored** storage, for goods that need a controlled
  temperature range but not full cold-chain handling.
- **Bonded** storage, for goods held under customs control before duty is
  paid.

A stock keeping unit (SKU), the identifier for a distinct product,
uses the storage type that the client contract and the product itself
require. It does not depend on which space happens to be free that day.

## Order picking and pack-out

When an order comes in, Wayfinder WMS generates a pick list using the
picking strategy each SKU requires.

:::info[Picking strategies]
Wayfinder WMS calculates picking priority automatically, using one of
three methods:

- **FIFO** (first in, first out): ships the unit received first,
  regardless of expiration date.
- **FEFO** (first expired, first out): ships the unit closest to its
  expiration date first.
- **FMFO** (first manufactured, first out): ships the unit with the
  earliest manufacture date first.
:::

Once the list is ready, you pick the items, pack them into the
appropriate shipping containers, and stage the completed order for
outbound handling.

## Outbound distribution

You verify packed orders against the original order one more time.
Then you hand the order off to the outbound carrier. This final check
catches a pick-and-pack error before it reaches the customer. This
requirement is why it exists as its own step, not an assumed part of
packing.
