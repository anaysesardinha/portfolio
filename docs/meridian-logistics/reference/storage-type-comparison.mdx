# Storage type comparison

:::info[Audience]
This page is for Warehouse Operations staff assigning inventory to
storage, and Account Managers scoping a client contract.
:::

Meridian fulfillment sites offer four storage types:

| Storage type | Description | Typical goods | Access requirements |
|---|---|---|---|
| Ambient | Standard storage with no temperature control | Goods with no temperature sensitivity | None beyond standard warehouse access |
| Climate-monitored | Storage that stays within a controlled temperature range and logs the temperature continuously | Goods sensitive to heat or humidity but not requiring full cold chain | Staff need training on the climate-monitoring system to access this storage |
| Cold chain | Refrigerated or frozen storage that stays at temperature end to end, from receiving to outbound | Perishable goods, such as food or pharmaceuticals | Staff need training on cold-chain handling to access this storage, and must log temperature continuously |
| Bonded (including Foreign Trade Zones, or FTZs) | Storage under customs control, before the client pays import duty | Imported goods awaiting duty payment or re-export | Staff need clearance for bonded-goods handling to access this storage; moving goods requires customs documentation |
