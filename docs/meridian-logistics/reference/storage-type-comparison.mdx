# Storage Type Comparison

:::info[Audience]
This page is for Warehouse Operations staff assigning inventory to
storage, and Account Managers scoping a client contract.
:::

Meridian fulfillment sites offer four storage types:

| Storage type | Description | Typical goods | Access requirements |
|---|---|---|---|
| Ambient | Standard storage with no temperature control | Goods with no temperature sensitivity | None beyond standard warehouse access |
| Climate-monitored | Storage held within a controlled temperature range, logged continuously | Goods sensitive to heat or humidity but not requiring full cold chain | Access limited to staff trained on the climate-monitoring system |
| Cold chain | Refrigerated or frozen storage maintained end to end from receiving to outbound | Perishable goods, such as food or pharmaceuticals | Access limited to staff trained on cold-chain handling; continuous temperature logging required |
| Bonded (including FTZ) | Storage under customs control, before the client pays import duty | Imported goods awaiting duty payment or re-export | Access limited to staff cleared for bonded-goods handling; customs documentation required for movement |
