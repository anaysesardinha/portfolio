# Document Types and Locations

:::info Audience
This page is for Warehouse Operations and Client Services staff looking
up where a document type is created or stored.
:::

| Document type | Purpose | System of record |
|---|---|---|
| ASN (advance shipping notice) | Lists a shipment's expected contents before it arrives | Wayfinder WMS |
| PO (purchase order) | A client's formal request to receive or ship a defined quantity | Wayfinder WMS |
| Discrepancy record | Logs a mismatch between a receipt and its ASN | Wayfinder WMS |
| Cycle count record | Logs a scheduled inventory count and any variance found | Wayfinder WMS |
| Escalation record | Tracks a variance that survived a recount, through to resolution | Wayfinder WMS |
| RMA (return merchandise authorization) | Authorizes a specific returned unit to re-enter a warehouse | Wayfinder WMS |
| SLA performance report | Reports Meridian's performance against contracted targets | ClearLane Visibility |
| Contract and scope documents | Set the commercial terms and services covered for a client | Client Services file, not a warehouse system |
