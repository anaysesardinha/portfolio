# Glossary

:::info[Audience]
This page is for anyone reading Meridian documentation who needs a term
defined.
:::

This glossary defines every domain term used across the Meridian
Contract Logistics sample, alphabetically:

| Term | Definition |
|---|---|
| 3PL | Third-party logistics provider. A company, such as Meridian, that manages warehousing, inventory, and distribution on behalf of a client. |
| ASN | Advance shipping notice. A document a supplier sends ahead of a shipment, listing its expected contents. |
| Bonded warehouse | A storage facility authorized to hold imported goods before the client pays customs duty on them. |
| Drayage | The short-distance transport of freight, typically between a port and a nearby warehouse. |
| FEFO | First expired, first out. A picking strategy that ships the unit closest to its expiration date first. |
| FIFO | First in, first out. A picking strategy that ships the unit received first, regardless of expiration date. |
| FMFO | First manufactured, first out. A picking strategy that ships the unit with the earliest manufacture date first. |
| FTZ | Foreign Trade Zone. A designated area where imported goods can be stored, assembled, or repackaged before formally entering customs territory. |
| Kitting | Assembling multiple individual SKUs into a single sellable unit before storage or shipment. |
| PO | Purchase order. A client's formal request for Meridian to receive or ship a defined quantity of goods. |
| RMA | Return merchandise authorization. A client's approval for a specific unit to be returned into a Meridian warehouse. |
| SKU | Stock keeping unit. The identifier for a single distinct product Meridian tracks in inventory. |
| SLA | Service level agreement. The performance targets a client contract sets for Meridian, such as order accuracy or shipping speed. |
| WMS | Warehouse management system. The software that tracks inventory, orders, and warehouse tasks. Meridian's internal WMS is Wayfinder WMS. |
